## 3. Implemented Capabilities Checklist

### Architecture Integration

Strict Layer Decoupling Preserved: Transfer resume logic operates entirely above Session. No TCP, socket, or transport-level code was modified.

Single Protocol Extension: One new FluxMessage variant (TransferResume) appended to the existing enum. No parallel protocol system created.

Module Isolation: All resume state persistence, negotiation, and recovery logic is housed within crates/flux-core/src/transfer/.

### Resume Protocol FSM:

Resume Negotiation: Receiver checks for valid partial state before responding to TransferRequest. Sends TransferResume { transfer_id, resume_from_chunk } instead of TransferAccept when resumable state exists.

Sender Skip Logic: Chunker::seek_to_chunk() uses AsyncSeekExt to jump to the correct byte offset without reading intermediate data.

Fresh Transfer Fallback: When no partial state exists, the protocol falls back to the standard S1.4 TransferAccept flow with zero behavioral change.

### Partial State Persistence:

Metadata Sidecar: .part.meta file (bincode-serialized PartialTransferState) written alongside .part data file.

Atomic State Updates: State is written to a .tmp file first, then atomically renamed, preventing corruption from mid-write crashes.

Write-Then-Record Ordering: Chunk data is flushed to disk before the resume state is updated, eliminating false resume horizons.

### Integrity & Safety:

Five-Point Validation on Resume: try_resume() verifies file_name, file_size, chunk_size, total_chunks, sha256, AND physical .part file size against the metadata sidecar.

Corrupt State Rejection: Mismatched or deserialization-failed .part.meta files are automatically purged, falling back to a fresh transfer.

Disk-Based Final Verification: SHA-256 is computed from the complete reassembled file on disk at finalization, ensuring correctness for both fresh and resumed transfers.

Triple-Point Verification Preserved: Chunk sequence + byte count + SHA-256 checks remain mandatory before .part → final rename.
